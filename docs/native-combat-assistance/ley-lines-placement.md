## One native search and original RSR selection

`PlanningFieldPlacement` represents observed available Ley Lines and an original
GCD weave deadline. It is neither a fabricated field object nor an assumed haste
modifier. Native charge/action status, unlock and saved RSR action opt-outs bind
preparation. The worker receives immutable values only. Both native normal and
AI-follow movement can prepare the complete route; it cannot commit a placement-bearing route until
RSR's original CanUse approves that same fresh opportunity. Missing or stale
preparation leaves the original action and timing intact. No native BMR rotation
prediction adapter, separate movement goal or external callback transport exists.

`RsrLeyLinesPlacement` uses the shared original-callback owner and the original
concrete action returned by native CanUse. The scope restores its exact factory;
foreign replacements retain ownership. Reflection failures return the original
selection result and yield locally. Field placement is independent of support
recipient, party and mitigation gates. The dormant former support placement
adapter was removed. Normal and AI-follow movement participate through the same
host. Existing follow goals retain their ranking; explicit destinations, manual
control, queued RSR commands, preview, force enable, PvP and unavailable movement
authority withhold optional placement. A preset without an active movement owner
cannot claim placement ownership. The former normal-only restriction was removed
after the 2026-10-24 caster run exposed it. Historical intercepted-action state
is not a current command; the live queued command remains authoritative.

`NativePlacementOpportunity` retains the original position and absolute deadline
across repeated native observations and the committed walk. Polling and CanUse
cannot renew it. A changed actor, zone or target cannot inherit it; expiry and
retirement require a later observed GCD to rearm. Active fields, casts, unavailable
charges, saved action opt-outs and unsupported occupied weaves withhold the
opportunity. A stale worker cannot approve or revoke another current opportunity.

## Objective, geometry and execution

The complete route preserves each current attack/heal, recipient, delivery time
and recovery before considering placement. Native goals, range, combo and party
contact retain their priorities. Among equal results, placement compares a
verified stationary window using the SAME timed traversal and last-safe exit
limits as walking. It does not predict another attack, invent hazard expiry,
promise a whole-fight optimum or grant haste from a field not yet observed.
The final useful position must remain inside the selected field to credit that
benefit. An intermediate placement/action stop and required onward escape belong
to the same route. The existing circle marker labels the placement stage.

The executor waits for the selected rotation at the exact stopped pose. The
original native callback revalidates the complete fresh route before releasing
Ley Lines. Action delivery remains RSR's responsibility. Own-player and the
native untargeted self-action sentinel are both valid effect identities. The
native field/timing observer supplies actual object, buff and cast/recast evidence
after execution. No fake object, renewed duration or independent action request
is added. Native manual, physical, assignment, action-lock and freshness gates
remain authoritative.

The old 1.2-second placement budget, six-yalm candidate neighborhood, 200 ms
demand refresh and fixed two-second retry do not survive. Actual GCD readiness,
original animation-lock evidence, native map coverage and scoped ownership replace
them. The existing twelve-second horizon and 250 ms native freshness ceiling
still apply. No new optimization quota was added.
