# Dun Scaith: Scathach repairs

Status: partial encounter repair, retained WIP maturity. Build and offline results are recorded by the raid-wide task owner; live xBMR/XCAI acceptance remains separate.

## Written guides reviewed first

Primary descriptive guide: <https://ffxiv.consolegameswiki.com/wiki/Dun_Scaith#Scathach> (normal level-60 alliance raid, Scathach section), reviewed 2026-10-14. It describes the three-hit Thirty Thorns combo followed by a melee burst, alternate diagonal Shadespin pairs, stop-movement Shadow Links, frontal Shadethrust, and facing tethered Shadow Limbs. The other raid encounters on that page were not treated as Scathach mechanics.

Additional written guide: <https://ffxiv.guide/hw/dun-scaith> (Scathach section). It identifies Thirty Cries as a stack on the main tank, Nox as consecutive baited explosions, and meteors as one-player minimum soaks. The guide's blanket suggestion to remain far away was not turned into a permanent melee exclusion. Safe future activation times remain available to the AI for uptime. The primary guide describes Shadethrust as telegraphed whereas the Pocket Guide says there is no ground telegraph; the recording has a real three-second NPC cast and the pinned Action row has no omen. The repair uses the cast cue and does not claim that a ground telegraph exists.

These descriptions do not prove dimensions, server snapshot timing, or safe routes.
